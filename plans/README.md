## Findings considered and rejected

(So nobody re-audits these.)

- **Scroll-spy via `getBoundingClientRect` on every scroll event**
  (`Header.tsx:26-45`): with 4–5 sections and a passive listener the real cost
  is negligible; an IntersectionObserver rewrite is churn without user-visible
  benefit. Revisit only if sections multiply.
- **Migrating sections off Motion to CSS-only animations** (would let sections
  become server components and cut client JS): real but modest payoff on a
  site this small and already fast on Cloudflare Workers; rebuilding a
  polished animation system isn't justified. Noted as a possible future spike.
- **`react-icons` bundle concerns**: per-subpackage imports
  (`react-icons/fi`, `react-icons/fa`) tree-shake fine in Next 16. No action.
- **`::selection` contrast**: not a WCAG AA failure class; left as designed.
- **Project cards: screenshots / clickable cards** (direction finding D3):
  presented to the owner 2026-06-12, not selected — adds asset weight to a
  deliberately light site. May be revisited.
- **Contact form via Cloudflare Worker + Resend**: evaluated as the contact
  channel; owner chose the LinkedIn CTA (plan 009) for zero maintenance.
  The form remains a valid future enhancement if direct messages matter later.
