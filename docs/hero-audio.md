# Hero audio

Ambient sea sound behind the hero scenes. On by default; the browser only lets it start after the
first click/tap/key on the page. The speaker icon next to `π` mutes it (remembered in `localStorage`
as `hero:sound`), volume lives in the `π` panel (`hero:volume`).

While the sound is on but still waiting for that first gesture, a two-line label ("♪ click / to listen",
`CursorHint.tsx`) trails the pointer with a small lag; it fades on the first click or key regardless of
whether the audio could start. Pointer devices only; no lag under reduced motion.

## Files

- `public/audio/horizon.ogg|m4a` — 50 s seamless loop from the calmest 53 s window of the recording (t=47.8 s, picked by short-term loudness, not by ear), −25 LUFS, low-passed again at runtime (distant sea).
- `public/audio/shore.ogg|m4a` — same, from the next calmest window (t=161 s), −24 LUFS.
- Both are high-passed at 150 Hz (rumble felt heavy) and low-passed at 6 kHz (hiss felt busy) when built.
- Opus (`.ogg`) everywhere except Safari, which gets AAC (`.m4a`). Fetched lazily, only when sound starts.

## Source

"Seawash (calm)" — Freesound #176617, **CC0** (public domain, no attribution required).
Found through the Openverse API (`api.openverse.org/v1/audio/?q=…&license=cc0,pdm&source=freesound`).
Candidates auditioned on 2026-10-17; everything else sounded too busy for the scenes.

## Rebuilding a loop

```bash
scripts/make-sea-loop.sh <recording> <horizon|shore> [start_s] [length_s] [target_lufs]
```

Cuts `length_s` (+3 s) from `start_s`, bakes a 3 s crossfade so the file end meets its start sample-exactly
(`AudioBufferSourceNode.loop` is then gapless), normalizes by plain gain to the target integrated loudness
measured with `ffmpeg ebur128` (not by ear), limits at −3 dBTP and encodes both formats. Prints the numbers.

## Synth mode (experiment)

The `π` panel → Sound → **Recording / Synth** switches the engine. Synth (`scenes/seaSynth.ts`) is pink noise
whose gain and low-pass follow a level/brightness curve extracted from the same recording every 50 ms
(`scenes/seaEnvelope.ts`, 3.4 KB, generated by `scripts/analyze-sea-envelope.py <recording> [start_s] [length_s]`).
It starts at a random point of the curve and wraps, so it never loops audibly; horizon gets the same distance
low-pass as the clip. Default stays the recording; the preference is `hero:soundSource` in localStorage.
